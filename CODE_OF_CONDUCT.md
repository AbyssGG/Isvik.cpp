# Code of conduct

Isvik.cpp welcomes people who contribute in good faith. Help keep project spaces respectful, useful, and focused on the work.

## Expected behavior

- Treat people with respect.
- Discuss ideas and behavior without personal attacks.
- Give actionable feedback and accept corrections.
- Respect different backgrounds, experiences, and viewpoints.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing another person's private information without permission.
- Deliberate disruption of project discussions or collaboration.

## Enforcement

Project maintainers may edit or remove content, close discussions, or restrict participation when behavior violates this policy. Contact the repository maintainers privately through GitHub to report a concern.

This policy applies to project issues, pull requests, discussions, and other project spaces.
