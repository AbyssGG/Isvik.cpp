# Security policy

Isvik.cpp runs local inference services and loads model files and native runtime libraries. Report security issues privately so maintainers can investigate them before public disclosure.

## Report a vulnerability

Use GitHub's private vulnerability reporting feature for the Isvik.cpp repository when it is enabled. If private reporting is unavailable, contact the repository maintainers through GitHub and request a private reporting channel.

Do not publish exploit details, credentials, personal data, or a proof of concept in a public issue.

Include the affected version or commit, operating system, backend, reproduction steps, and impact. Remove secrets and private model data from logs before sharing them.

## Supported versions

Security fixes target the latest release and the default development branch. Older releases may not receive updates.
